# 多语言键盘原型

## 使用

在“键鼠”页，点击原 Win 键位置的 **中/EN** 切换语言。
也可以在“设置 → 键盘 → 键盘语言”中更改并保存。语言选择保存在原有
`~/.config/thor-panel/config.json` 的 `keyboard_language` 字段；其他设置保留。

不常驻语言栏，空闲时触控板和键帽均保持原来的大小。中文组合或后端
状态提示才临时浮显候选条，确认/取消后自动收起。原 Win 触摸键不再发送
Super 键。保留原有键鼠分屏布局，不提供放大键盘功能。

中文目前提供简体全拼：

- 输入拼音，在下屏查看候选；点候选、按数字 1–6 或空格选词。
- “上页/下页”翻候选；选择前缀词后，未消费的拼音保留。
- 退格先删除拼音，空拼音时才删除上屏文字。
- 回车在组合期间提交原始拼音；没有组合时发送回车。
- Esc /“取消”清除未完成输入；常见标点使用中文形式。
- Ctrl/Alt/Super 快捷键沿用原有物理按键通道；复杂快捷键建议切回英文。

只有用户选择中文且键盘可见时才启动中文后端。切出键盘、收起、关闭、
切回英文都会停止该后端。保持默认不开机自启。

## 系统接口与兼容边界

1. `keyboard_xkb.py` 用系统 libxkbcommon 创建私有布局状态，不修改实体键盘
   或系统的布局。当前面板先开放英文 US 和中文拼音。
2. `pinyin_engine.py` 在独立 worker 中调用系统 libpinyin 与词库。
   不加载现有用户词库，不训练或保存个人词频；工作文件位于临时目录，
   worker 正常退出时删除。库和词库均不随本项目重新分发。
3. `keyboard_composition.py` 串行处理输入、候选选择和提交，候选携带版本号，
   防止快速打字后点到旧候选。上屏输入目标变化时取消组合。
4. `gamescope_text.py` 是单独隔离的 **私有协议适配器**。只连接经同用户
   socket/进程身份校验的上屏 Gamescope；绑定协议版本 1 的文字子集，
   仅接受目前已知的 manager 版本 1–3。它不发送鼠标事件、不接管 Steam
   输入服务。私有接口并非官方保证供普通 Wayland 应用使用的稳定 API。

本轮设备没有 Fcitx5/IBus 服务，只有系统 libpinyin，因此没有安装或启用
新的系统输入法服务。后续可为已有 Fcitx5/IBus 的系统增加独立适配器，
复用同一个语言/候选界面。

Game Mode 中文是当前原型的目标。Desktop Mode 中文暂不启用，面板显示
限制说明，可切回英文。Steam、Chrome、原生游戏及 Proton 内文字框需要
逐项交互验收；测试窗口成功不代表所有游戏都支持 Unicode 文字输入。

## 性能与输入生命周期

- GTK 回调不读取词库、不等待子进程、不为每个按键启动命令。
- 使用一个按需启动的持久 worker，空闲阻塞等待消息；不捕获上屏画面。
- 队列有界、命令过期、进程响应有超时；失败清除组合并显示不可用。
- 不自动重放失败的文字提交。页面切换关闭旧 worker，迟到回复失效。
- 拼音、候选和提交文字只在内存/匿名管道中传递，不记入应用日志。

## 验证记录

2026-10-20，AYN Thor / Armada 20261010：

- **设备自动验证**：系统 XKB 的 Shift/Caps/符号，以及德文、法文、俄文
  私有 keymap 生成字符通过；其他语言面板尚未开放。
- **设备自动验证**：系统 libpinyin 的 `nihao → 你好`、`zhongwen → 中文`、
  `shijie → 世界`、不完整音节及部分选词通过。
- **专用窗口验证**：`tools/keyboard_text_probe.py --run-own-window-test`
  仅对自己创建的上屏 GTK 输入框发送合成文字，确认 Unicode 提交、
  独立 worker、快速输入后空格选词、不泄漏原始拼音和隐藏时取消通过。
- **用户交互验收**：用户确认候选显示正常，中文与英文都能输入。
  用户确认恢复后的键帽大小合适，但触控板变小；已按建议将 Win 改为
  语言切换键，移除常驻栏、恢复完整触控板，候选改为临时浮层，待复测。
  测试不向真实游戏或 Steam 输入框自动打字。

Mac 上会跳过 Linux GTK 和系统库检查；不能把这些跳过项算作设备通过。

## 回退

切回 `English · US` 会停止中文 worker 并继续原有按键通道。
若需要撤回整个原型，使用安装工具回退到此前的应用版本；安装器不修改
官方 Armada/Steam/Gamescope 服务，不修改驱动或开机自启设置。
