# 使用虚拟键鼠

安装完成后打开桌面或应用菜单中的 **虚拟键鼠**，进入 Steam Game Mode。面板只使用官方下屏会话，不停止官方下屏服务。

| 控件/模式 | 操作 |
| --- | --- |
| 触控板 | 单指移动、轻点点击，双指滑动滚轮 |
| 键鼠 | 上方触控板、下方键盘；当前页可见时临时抑制 Steam 原生键盘 |
| 定位触摸 | 第一指相对移动上屏圆环；保持第一指，第二指按住触摸；移动第一指拖动，第二指抬起释放 |
| 定位居中 | 释放旧触点并将圆环居中，抬手后恢复 |
| 释放按键/触点 | 清除保持状态；定位模式下同时暂停触摸 |
| 收起 | 缩为窄条，点击可展开 |
| 关闭 | 释放输入并退出，不自动重开 |

定位圆环蓝色表示仅定位，橙色表示触点按下；移动倍率目前为 2.0。切换界面后先抬起所有手指，旧手势不续接。
面板不自动加闲置变暗遮罩。顶部设备监控为只读，电源、亮度、官方下屏服务仍由 Armada 管理。

设置保存在 `~/.config/thor-panel/config.json`。滚轮使用 `scroll_speed`（1～5）和 `scroll_scale`（大于 0、不超过 1）共同调整，改动前请退出面板并备份配置。
只调整滚轮时可使用 `scroll_speed=1`、`scroll_scale=0.25` 作为起点；安装器不替你覆盖已有设置。

如 Ctrl/Shift 等保持导致意外组合键，使用“释放按键”。需要 Steam 自己的整段文字输入对话框时，先收起面板或切到触控板页。
